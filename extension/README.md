# PlushVote Chrome 插件（采集助手）

## 功能
- 一键采集当前小红书帖子（标题、正文、多图）
- 预览并编辑内容后提交到 PlushVote 现有平台接口
- 自动读取平台浏览器登录态（Supabase token）
- 未登录时提示并可一键跳转平台登录页
- 平台基础地址可配置（本地/线上可切换）

## 安装
1. 打开 Chrome `chrome://extensions`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本目录：`extension/`

## 使用
1. 打开小红书帖子页面（`/explore/...` 或 `/discovery/item/...`）
2. 点击插件图标，点击“一键采集当前页面”
3. 在预览页编辑内容、勾选图片、调整顺序（首次提交会弹出平台域名授权）
4. 点击“提交到平台”

## 登录说明
- 插件会尝试读取你在平台站点（如 `http://localhost:3000`）的登录态。
- 若提示未登录，点击“去登录平台”，登录后回到预览页再次提交。

## 平台地址配置
- 在插件“设置”中修改平台地址。
- 示例：
  - 本地：`http://localhost:3000`
  - 线上：`https://your-domain.com`

## 说明
- 当前后端接口仍以 `imageUrl` 单图字段为主；插件同时提交 `imageUrls` 以兼容后续多图后端升级。
